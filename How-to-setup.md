welcome. You might have come from the 'readmefirst.md' file
well in this file, you will learn how to setup ExplorerPatcher on windows 11.
First of all open any web browser like Chrome, Firefox, edge, Brave or any kind of browser that works
next, go to the official ExplorerPatcher github Page
link: https://github.com/valinet/explorerpatcher
just copy and paste the link into your browser
next, scroll down and click Releases
then download the Latest epsetup.exe file
next, open the file and allow the prompts
then your taskbar will go blank for 2-3 seconds and then return back to the windows 11 Default taskbar
next, go to settings and search taskbar settings. 
next scroll down to taskbar alignment and change it from center to left.
then close settings, right click taskbar and click properties.
then change taskbar from windows 11 (default) to windows 10 (ExplorerPatcher)
next go to 'file explorer' and click on 'disable windows 11 context menu' and make sure beside it shows a tick mark
next go to 'start menu' and change start menu style to windows 10.
next click Restart explorer
wait a few seconds
and boom. you get the classic and iconic windows 10 Taskbar, context menu and start menu on windows 11
to make it a more authentic feel, download the default windows 10 light wallpaper from https://wallpapercave.com/w/wp7283005
go to file explorer, find the image, right click it and choose set as desktop background
Enjoy :3
